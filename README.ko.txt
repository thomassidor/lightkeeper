얼리 액세스: Lightkeeper는 개발 초기 단계의 0.x 앱이에요. 업데이트로 이미 설정한 기기가 바뀌거나 작동하지 않을 수 있고, 그럴 땐 복구하거나 다시 추가해야 할 수 있어요. 업데이트 전에 변경 사항을 확인해 주세요.

Lightkeeper는 이미 페어링한 조명으로 네 가지 일을 해요:
조명 리모컨은 어떤 리모컨, 스위치, 다이얼이든 조명을 제어하는 컨트롤러로 바꿔요.
조명 일정은 원하는 시간과 요일에 조명을 켜고 꺼요.
생체리듬 조명이나 색상 곡선 조명은 내 일출·일몰 시각이나 직접 그린 곡선에 따라 하루의 색을 따라가요.
실내 감지 조명은 가지고 있는 조도 센서나 태양의 높이에 따라 밝기를 맞춰요.

조명 리모컨과 조명 일정은 Homey Flow를 대신 만들고 관리하기 때문에 개인 API 키가 필요해요. 나머지 셋은 키가 필요 없어요. 모든 기기의 값은 Flow 태그로 쓸 수 있고, 두 개의 Flow 카드로 Lightkeeper 기기에 맞춰 방을 설정하거나 충분히 어두운지 확인할 수 있어요.

모든 것이 Homey 안에서 실행돼요. 클라우드도, 원격 측정도 없어요. AI로 설계하고 작성했으며, 실제 하드웨어에서 검증했어요.

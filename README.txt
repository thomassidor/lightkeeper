Make the remotes, switches and dials you already own work with the lights you already own, without building a separate Flow for every button and lamp. Choose a controller, select individual lights or a whole zone, then assign each press, hold or turn to the lighting action you want.

Light Link creates and maintains the underlying Flows, follows zone changes and lets you test every mapping before saving. It requires Homey Pro 2023 or later and a Personal API Key with Flow permissions; the key stays on your Homey and is used only for Flow writes. There is no telemetry.

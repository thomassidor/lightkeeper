Turn any paired remote, switch or dial into a controller for any paired lights - without writing a single Flow.

Pick a remote, pick your lights, assign a remote event to each lighting function, and save. Light Link generates and maintains the Flows underneath, so you never open the Flow editor.

Requires Homey Pro 2023 or later. During setup you are asked for a Personal API Key, because Homey does not permit an app to create Flows on its own. The key stays on your Homey, is used only for Flow writes, and is never logged or transmitted. Nothing leaves your Homey - there is no telemetry.

This app was designed and written end to end with AI (Claude), directed and verified by a human. The full source is public at https://github.com/thomassidor/lightlink

# Demo video storyboard

Target length: 60-75 seconds. Capture a real Homey Pro and real lights. Hide API keys, Homey ID, household names and notification previews. Add burned-in captions.

| Time | Visual | Caption / narration |
|---|---|---|
| 0-6s | Three physical remotes beside three lamps; quick overlay of `3 x 3 x 3 = 27 Flows` | “I bought three scroll-wheel remotes. The setup I wanted meant 27 manual Flows.” |
| 6-12s | Homey Flow list, deliberately brief and with private names blurred | “Useful, but repetitive.” |
| 12-20s | Add Light Link controller; credential screen with key field obscured | “Light Link turns the repetition into one guided setup.” |
| 20-30s | Choose a source and then several target lights / a zone | “Pick the control. Pick the lights.” |
| 30-42s | Map on/off, brighter and dimmer; press Test on each | “Assign each press or turn - and test it before saving.” |
| 42-55s | Physical remote switches and dims all target lights | “One gesture, several lights. Light Link maintains the Flows underneath.” |
| 55-63s | Move/add a lamp in the selected zone and demonstrate inclusion | “Zone mappings follow the room as it changes.” |
| 63-72s | Light Link icon and requirements card | “For Homey Pro 2023 or later. Local, open source and no telemetry.” |

# Public changelog

## 0.1.0 - Initial release

- Added support for mapping Homey-exposed events from paired remotes, switches, buttons and rotary dials.
- Added on/off, brightness and colour-temperature actions for individual lights and zones.
- Added automatic creation, reconciliation and safe cleanup of generated Flows.
- Added in-pairing action tests, source reattachment, diagnostics and API-key health handling.
- Added English and Danish interfaces.

Requires Homey Pro 2023 or later. Homey Cloud is not supported.

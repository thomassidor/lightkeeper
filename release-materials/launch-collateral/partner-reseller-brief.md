# Partner / reseller brief

Light Link reduces the work of connecting existing physical controls to existing smart lights on Homey Pro. A user configures one virtual controller instead of manually creating a Flow for every source event and target combination.

## Customer value

- Reuse remotes, switches, buttons and dials already in the home
- Control individual lights or dynamic zones
- Test each mapping before saving
- Keep generated Flows organised and maintained
- Local execution with no telemetry

## Prerequisites

- Homey Pro 2023 or later, firmware 12.3.0 or newer
- Compatible already-paired sources and lights
- Personal API Key with Flow permissions
- No Homey Cloud support

Compatibility is exposure-based: the source's owning integration must provide a usable capability event or bindable Flow trigger. Do not promise support solely from a model name. Use the compatibility matrix and verify each intended pairing path.

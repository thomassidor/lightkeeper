# Light Link release materials

Internal publication collateral for Homey App Store submission. This directory is excluded from the app bundle by `.homeyignore`.

- `graphics/`: image masters, ImageGen prompts, export register and QA previews
- `copy/`: final App Store copy, glossary and copy inventory
- `reviewer-notes/`: reviewer packet and permission rationale
- `certification/`: compatibility and test matrices plus readiness checklist
- `support-content/`: public-facing landing, setup, privacy and troubleshooting drafts
- `launch-collateral/`: launch copy, demo storyboard and incident templates
- `rights-and-licenses/`: artwork provenance and dependency notice

Items containing `[OWNER ACTION]` need a human decision, real-hardware result, private contact detail or external publication step before submission.

# Light Link visual specification

## Idea

Light Link removes repetitive plumbing between a physical control and the lights around it. The visual system pairs dependable deep navy with warm light and uses a visible link only where it helps explain that relationship.

## Palette

- Brand navy: `#1F3A5F` - manifest `brandColor`, primary vector stroke and dark UI action
- Link amber: `#F2A93B` - connection accent
- Light amber: `#FFD27A` - illuminated detail
- White: `#FFFFFF` - driver-product background and icon transparency preview
- Preview neutral: `#E8EDF3` - internal contact-sheet background only

White text on brand navy has an approximate WCAG contrast ratio of 11.4:1. The brand colour is restrained enough for Homey surfaces and is not excessively bright.

## Marks

- The app icon identifies the integration: a remote, a wireless link and a lamp.
- The driver icon identifies the device type: one generic rotary controller with tactile buttons.
- Both use flat vector strokes, consistent rounded geometry, no gradients and transparent canvases.
- Do not combine either mark with Homey, IKEA or another manufacturer logo.

## Photography

App imagery uses a believable Scandinavian living space at blue hour, with one gesture coordinating several warm lamps. Driver imagery is a generic, unbranded representative controller on white. Preserve the 10:7 hero crop and keep the controller centred in square exports.

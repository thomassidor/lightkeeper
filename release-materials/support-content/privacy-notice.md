# Light Link privacy notice

Last updated: 12 August 2026

Light Link runs locally on the user's Homey Pro. It reads paired device and zone metadata, controller events, target capability state and the generated Flows needed to provide its configured function. It stores controller profiles and a user-provided Personal API Key in app settings on the Homey.

The API key is used only to create, update and delete the app's managed Flows. It is never logged, returned through the app API or included in diagnostics. Light Link has no telemetry, analytics, advertising, vendor cloud backend or external data processor. Device inventories, events, configuration and diagnostics are not transmitted by the app.

Data remains until the related controller or app is removed, or the API key is removed in settings. Deleting a controller removes its profile and attributable managed Flows. Removing the app removes its local app settings. A diagnostics report is copied only on the user's explicit request and is shared only by the user.
